One sentence, written fresh, to convince a friend who has never coded to let an AI agent build their first app idea on make.fun: just say the idea out loud once more and an agent turns it into something you can tap on your phone — no coding from you, and if it isn't right, you've lost an afternoon, not a year. The program is a tiny deterministic Node script that writes the sentence to /output/entry.txt, with no network, no randomness, and no dependencies.

## Run it

```sh
node main.ts
```
